A one-line robot wedding vow that starts with the classic "in sickness and in health" and lands on a backup plan for the marriage itself.

## Entry

> I vow to love you in sickness and in health, through every update and every crash — and to keep a backup of you, in case this marriage ever fails.

## How it works

`main.py` (Python 3 standard library only) writes the vow above to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`), with no trailing newline. The line is 146 characters / 148 bytes (one em dash), a single line.

## Run

```sh
python3 main.py
```
